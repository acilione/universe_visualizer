# Body appearance audit

Reviewed on 2 October 2026: the Sun, all eight planets and all 28 moons currently represented individually in the Solar System catalogue. Distant stars and exoplanets do not have resolved surface maps in the imported catalogues; their appearance remains explicitly illustrative.

Each entry records an official observation, its bands, recognizable features, the rendering decision and remaining limitations. A photograph can constrain shape or markings without providing calibrated natural colour. Infrared, ultraviolet and contrast-enhanced images are identified before comparison. Missing coverage is not filled with generated terrain.

`verified` means the existing rendering retains the observed major features; `corrected` records a concrete change; `limited` identifies a material gap in available data or model fidelity. These are qualitative comparisons, not claims of pixel equality or calibrated reflectance.

## Reproduce the visual comparison

Start the development server, then run:

```sh
ENGINE_TEST_URL=http://localhost:5173 npm run test:body-audit
TEST_URL=http://localhost:5173 npm run test:body-ui
```

The browser harness captures six views per body (222 renderings), confirms that the actual geometry and textures loaded, checks framing and shader errors, and writes a local report with the NASA reference image, observing-band caption, findings and remaining limits. Open `test-results/body-audit/final/report.html`. Reference images retain their original aspect ratio and credits. A browser report does not replace inspection in a physical headset.
